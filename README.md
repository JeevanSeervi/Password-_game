# Password Please — BCA Password Challenge

A humorous password-validation game built with HTML, CSS, and JavaScript. The challenge checks a password against 30 increasingly specific rules and gives funny feedback along the way.

## Features

- 30 password rules, including character, word, number, emoji, and ordering requirements
- Rule-by-rule validation with Hinglish-style feedback
- A completion screen with an original cartoon reaction
- Responsive layout for desktop and mobile
- Runs as a static page; no build tools or package installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

## GitHub Pages

To publish it as a shareable website:

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **GitHub Actions** and save.
3. Open the **Actions** tab, select **Deploy Password Please to GitHub Pages**, then choose **Run workflow** if it has not started automatically.
4. Once deployment succeeds, open **Settings → Pages** and click **Visit site**. Future pushes to `main` will deploy automatically.

## Privacy note

This is a demo game, not a real authentication system. Do not enter any real or reused password. The page is designed to validate the text locally in your browser. Google Sheets submission is not configured in this repository.
