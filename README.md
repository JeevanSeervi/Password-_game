# Password Please — BCA Password Challenge

A humorous password-validation game built with HTML, CSS, and JavaScript. The challenge checks a password against 29 increasingly specific rules and gives funny feedback along the way.

## Features

- 29 password rules, including character, word, number, emoji, and ordering requirements
- Rule-by-rule validation with Hinglish-style feedback
- A completion screen with an original cartoon reaction
- Responsive layout for desktop and mobile
- Runs as a static page; no build tools or package installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

## GitHub Pages

To publish it as a shareable website:

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. After GitHub finishes publishing, open **Settings → Pages** and click **Visit site**. Future pushes to `main` will update the site automatically.

## Privacy note

This is a demo game, not a real authentication system. Do not enter any real or reused password. The page is designed to validate the text locally in your browser. Google Sheets submission is not configured in this repository.
